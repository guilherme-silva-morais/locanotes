# locanotes

Sistema de anotações — teste técnico Locaweb. Backend Rails 8.1 API-only + frontend Vue 3.5 SPA.

> 🚧 Em construção. Setup definitivo via `Makefile` chega no fim da Fase 1.

## Pré-requisitos

- Docker Desktop (com Compose v2)
- GNU Make

## Setup (provisório)

```bash
cp .env.example .env
docker compose up --build
```

A configuração final do Makefile e do Compose vem nos próximos commits desta fase.
